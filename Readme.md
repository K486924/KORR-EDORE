
# KORR EDORE

A procedural first-person horror game.

## Project vision
Create a distinctive horror experience using entirely code-generated 3D geometry, procedural materials, animation, lighting and sound.

## Development targets
- Android and desktop browsers
- WebGL rendering
- Modular JavaScript architecture
- First-person gameplay
- Offline standalone HTML release

## Asset policy
All 3D models, environments, materials and creatures will be procedurally generated. No downloaded 3D models.

## Current stage
Repository setup and procedural engine development.
