# KORR EDORE

A procedural-first, first-person horror game built for Android and desktop browsers.

## Principles
- All 3D geometry, characters, props, environments and materials are generated by our own code.
- No downloaded 3D models or texture packs.
- First-person controls for Android touch and desktop mouse/keyboard.
- Context-sensitive interaction: the centre reticle shows an action only while targeting a valid object.
- Modular development, with an eventual single-file offline HTML release.

## Current stage
Repository foundation and procedural engine architecture.
